Jev X Blocker Privacy Policy

Jev X Blocker is a local-first Chrome extension that hides high-confidence porn, sexual innuendo and solicitation posts and replies on X (x.com). This page explains what data the extension handles, how, and the controls you have.

What is sent

When a post or reply enters the check flow, the extension sends the merged author name and post/reply text to the TypeSafe Jev API (https://api.typesafe.ai/v1/systemone) that you configure yourself, for a semantic probability judgment. Nothing else leaves your browser.

What is never sent

  • X cookies, login state or session tokens
  • Browsing history and tab information
  • Images, videos or avatars
  • Your TypeSafe API key never enters the X page DOM, URLs or logs, and is never sent to the extension developer
  • No data ever reaches the extension developer's servers — this extension has no backend

Local storage

  • The TypeSafe API key is stored in chrome.storage.local and read only by the extension's service worker
  • Filter settings (rules, thresholds, scopes) are stored locally
  • The classification cache stores only a hash of "author + text" with the probability result — never raw text; clear it anytime in Settings
  • Statistics are counters only (requests, hidden) with no text content

Your controls

  • Replace or delete the API key anytime in Settings
  • Every hidden item can be restored with one click ("View post / View reply")
  • Filter scopes (replies / root post / timeline / search / profile / explore) are individually toggleable
  • Every rule can be edited, disabled or deleted

API provider

Text judgment is performed by the TypeSafe Jev API, which is subject to TypeSafe's own terms and privacy policy — see the TypeSafe website for details.
