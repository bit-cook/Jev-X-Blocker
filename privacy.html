Jev X Blocker 隐私政策

Jev X Blocker 是一个本地优先的 Chrome 扩展，用于在 X（x.com）上隐藏高置信度的色情、性暗示与色情引流帖子和评论。本页面说明扩展处理哪些数据、如何处理，以及你拥有的控制权。

发送了什么

当一条帖子或评论进入检查流程时，扩展会把用户名和帖子与评论正文合并后的文本发送到你自行配置的 TypeSafe Jev API（https://api.typesafe.ai/v1/systemone），用于语义概率判断。除此之外没有其他内容离开你的浏览器。

不会发送什么

  • X Cookie、登录信息或会话 Token
  • 浏览历史与标签页信息
  • 图片、视频、头像
  • 你的 TypeSafe API Key 不会进入 X 页面 DOM、URL 或日志，也不会发送给插件开发者
  • 任何数据都不会发送给插件开发者的服务器——本扩展没有后端

本地存储

  • TypeSafe API Key 保存在 chrome.storage.local，只有扩展的 service worker 读取
  • 过滤配置（规则、阈值、范围）保存在本地
  • 分类缓存只保存"用户名+正文"的哈希 key 与概率结果，不保存原文；可在设置中一键清除
  • 统计只记录请求数、隐藏数等计数，不含任何文本内容

你的控制权

  • 随时可以在设置中心更换或删除 API Key
  • 每条被隐藏的内容都可以点击"查看"恢复
  • 可以按范围（评论 / 主帖 / 时间线 / 搜索 / 主页 / 探索）开关过滤
  • 可以修改、停用或删除任何过滤规则

API 供应商

文本判断由 TypeSafe Jev API 完成，该请求受 TypeSafe 自身的服务条款与隐私政策约束。请参考 TypeSafe 官网的相关文档。
