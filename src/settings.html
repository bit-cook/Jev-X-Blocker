◇过滤规则编排

内置分类准则与自然语言规则。模型只返回概率，本地决定是否达到隐藏阈值；每条规则可选择只作用于评论或帖子。

□显示与交互

隐藏的内容不会被删除，用户可以在原位置恢复查看。

显示隐藏占位符

用"已隐藏一条帖子/评论"和命中规则替换原内容。

显示检查按钮

鼠标移动到帖子和评论区域时，显示单条检查入口。

显示页面检查浮窗

在 X 页面右侧显示"检查情况"浮窗。关闭后过滤照常进行，只隐藏这个浮窗；也可以直接点浮窗面板里的"隐藏浮窗"。

显示置信度

在占位符上显示命中规则的概率，帮助用户判断是否恢复。

判断完成前隐藏新内容 实验性

默认关闭。开启会减少短暂闪现，但 API 慢时内容会保持隐藏。

▥API 配额与成本防护

缓存相同内容，限制每日请求量，不继续静默产生 API 成本。
